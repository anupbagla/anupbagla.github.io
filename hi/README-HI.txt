ANUP BAGLA — HINDI COMPANION WEBSITE
====================================
Upload the CONTENTS of this folder into a folder named `hi` in the root of:
https://github.com/anupbagla/anupbagla.github.io

Files:
- index.html
- journey.html
- contribution.html
- education.html
- research.html
- projects.html
- consciousness.html
- dialogue.html
- style.css

The English website files in the repository root are not changed by this package.
The Hindi pages link back to the corresponding English pages using ../<page>.html.
The birthday reflection image is referenced as ../birthday-72-journey.png, using the existing root-level image.

After upload, test:
https://anupbagla.github.io/hi/

Notes:
- Dialogue responses are prepared in the visitor's email app; they are not stored on the website.
- The same GA4 property ID as the English site is used. Remove or change it only if you do not want combined analytics.
- Google Fonts are loaded online, with local system-font fallbacks.
- All page-to-page links are relative and remain within /hi/.
